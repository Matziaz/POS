# POS Polimórfico

Sistema de Punto de Venta (POS) diseñado para micro-comercios, enfocado en:
- Operación offline
- Adaptabilidad por tipo de negocio
- Uso en hardware de bajo costo (Raspberry Pi)
- Generación de información accionable para el comerciante

## Estado del proyecto
En desarrollo activo (fase MVP).

## Objetivo
Construir un POS mínimo funcional que permita registrar ventas,
adaptarse al tipo de comercio y generar recomendaciones simples
sin requerir capacitación técnica.

## Alcance inicial
- Registro de productos
- Registro de ventas
- Persistencia local
- Corte de caja diario

## Hardware objetivo
- Raspberry Pi
